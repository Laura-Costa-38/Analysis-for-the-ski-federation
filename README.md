As part of my Master’s program, I worked with real-world downhill skiing data to analyze and visualize skier performance. The project focused on comparing skiers both individually and relative to others on the same course, aiming to identify strengths and areas for improvement. I designed an interactive dashboard using RShinyDashboard, which allowed dynamic exploration of performance metrics, highlighting patterns and differences across runs. This project helped me gain experience in data visualization, performance analysis, and interactive dashboard design in a sports context.
